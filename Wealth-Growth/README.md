## 🛠️ 本栏目工作流（与 VLA-WM 论文区的区别）

这一栏是**纯读书笔记**，工作流比论文那一侧要轻：

| 项目 | VLA-WM（论文） | Wealth-Growth（书） |
|---|---|---|
| 保留原文 | ✅ 完整批读，原文 + 内嵌批注 | ❌ 只产出我自己的摘要和笔记 |
| 拷打 Q&A | ✅ 每节一轮，回写到 section | ❌ 不做（这一边以吸收和应用为主） |
| 图片 | ✅ 提到 Figure 必须嵌入 | 🔵 选嵌：核心模型图 / 框架图 / 案例数据值得就嵌 |
| 主要输出 | `sections/*.md`（原文 + 批注 + 🔥 拷打） | `notes/*.md`（章节笔记 + 金句 + 行动项） |

## 📂 单本书目录结构

```
[作者] 书名/
├── README.md          ← 书的概览 + 一句话总结 + 章节导航 + 核心模型清单
├── notes/             ← 章节笔记（按书的章节切分）
│   ├── 00-overview.md
│   ├── 01-xxx.md
│   └── ...
├── frameworks/        ← 核心模型 / 框架 / 公式（图 + 文字解读），便于以后回看
└── book.pdf           ← 原始 PDF
```

`frameworks/` 是可选的——如果一本书没什么需要单独沉淀的"模型图"，可以不建。

## 📝 笔记语义约定

| 标记 | 含义 |
|---|---|
| `📌` | 关键观点 / 核心论点 |
| `🧠` | 模型 / 框架 / 公式 |
| `💬` | 金句 / 值得直接抄下来的原文 |
| `💡` | Claude 的批注：术语解释、案例补充、跨书概念对比 |
| `🎯` | 行动项：读完之后我应该怎么用 |
| `🤔` | 问号 / 我不同意的地方 / 想自己验证的假设 |
| `⚠️` | 容易理解错 / 容易踩的坑 |

## ✍️ 笔记节奏建议

- **一章一篇 `notes/NN-章节名.md`**，篇幅不限，重在能复述清楚
- 章节笔记顶部写**这一章解决了什么问题**，结尾写**这一章给我留下的行动项**
- 读完整本之后，回到本书 README 把「一句话」「核心模型」「我为什么读这本」补完
