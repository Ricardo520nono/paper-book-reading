## 🎯 这一栏想啃下的核心问题

读这一栏的论文时，我**始终带着这 4 个问题**进文章。每篇 paper 至少能让我在其中 1~2 题上更新自己的认知，就值。

1. **数据**：金融文本数据的「质量 / 时效性 / 可得性」三角，业界目前的最佳实践到哪一步了？
2. **架构**：FinLLM 的主流路线是「从零训」、「general LLM + LoRA 微调」，还是「general LLM + RAG + tool use」？三条路线分别适合谁？
3. **评测**：金融任务的好 benchmark 长什么样？情绪分析的 F1 → 真实交易 PnL 之间的桥梁是怎么搭的？
4. **落地**：哪些 application（robo-advisor / quant trading / 风控 / 投研）已经能跑通商业化，哪些还卡在哪？

|---|---|
| `💡` | Claude 的批注：术语解释 / 背景补充 / 对比 / 重组 |
